경영정보학과(MIS) 진로 가이드

IT + 경영 융합 인재를 위한 커리어 전략

1. 주요 직무 방향

  • IT 비즈니스 분석가 (BA / PM) - 서비스 기획 및 프로세스 개선
  • 데이터 분석가 - 데이터 기반 의사결정 지원
  • ERP 컨설턴트 - SAP, Oracle 시스템 구축
  • 핀테크 / 금융 IT - 금융 + IT 융합 직무

2. 시장 트렌드

  • 디지털 트랜스포메이션(DX)
  • AI 활용 능력 중요
  • 비즈니스 문제 해결형 인재 선호

3. 커리어 로드맵

  • 인턴십 및 프로젝트 경험 필수
  • 데이터 실무 경험 확보
  • 기술 + 기획 역량 동시 강화

4. 추천 자격증

  • ADsP (데이터분석 준전문가)
  • SQLD (SQL 개발자)
  • 정보처리기사
  • 컴퓨터활용능력 1급

5. 지역별 취업 전략

부산

  • 한국거래소
  • 기술보증기금
  • 한국자산관리공사

제주

  • 공무원연금공단
  • 제주국제자유도시개발센터
  • 제주특별자치도개발공사

6. 핵심 전략

  • 데이터 + IT + 커뮤니케이션 역량 확보
  • NCS 준비 필수
  • 지역인재 전형 적극 활용
